# photon2718

情報系の大学1年。Claude Code を使った AI 駆動開発で、身の回りの不便を解決するアプリを作っています。
コードの大半は AI が書き、私は「何を作るかの決定・仕様の指示・動作確認とデバッグ・公開と運用」を担当しています。
主な成果物は非公開リポジトリで管理しています。

## 作ったもの
- **試験対策教材の共有アプリ**（iOS / Android / macOS / Windows・App Store 公開）
  教材の流出をきっかけに開発。スクリーンショット・画面録画の禁止、Discord 認証。現在 15 人で運用中
- **教材配信の仕組み**（Cloudflare Workers / Cron Triggers / Discord Webhook）
  アクセス用 URL を毎時自動で更新し、Discord に反映
- **家計簿アプリ**（SwiftUI / SwiftData / CloudKit・iPhone と Mac で同期）
